# Jira Deep Scan Rules

Always inspect both subtask and parent story.

Scan:

- Subtask description
- Subtask comments
- Subtask attachments
- Subtask linked issues
- Parent story description
- Parent story comments
- Parent story attachments
- Parent story linked issues

Extract and classify:

- Figma/design links
- Backend TRD links
- API contract links
- GraphQL schema links
- OpenAPI/Swagger links
- Confluence/Docs/Notion links
- Google Docs links
- Postman collections
- Jira attachments
- Supporting product docs

Report inaccessible references as warning or blocker.
