# Requirement Alignment

Compare:

- Jira Acceptance Criteria
- Figma design
- Backend TRD/API contract
- Existing codebase

Output:

- Confirmed requirements
- Gaps
- Conflicts
- Assumptions
- Blockers
- Clarification questions

If a conflict affects behavior, API contract, or UI, stop and ask for human clarification.
