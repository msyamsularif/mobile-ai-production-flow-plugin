# Backend Contract Research

Use this skill when Jira references BE TRD/API contract or when implementation requires API integration.

Extract:

- API type: GraphQL / REST / OpenAPI / other
- Endpoint/query/mutation
- Request payload
- Response payload
- Nullable fields
- Error codes and mobile behavior
- Auth requirements
- Feature flag/rollout requirements
- Contract risks and open questions

Stop if API implementation is required but no accessible backend contract exists.
