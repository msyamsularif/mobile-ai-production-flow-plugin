# Figma Design Research

Use this skill when Jira references Figma or when the ticket affects UI.

Extract:

- Affected screens
- UI components
- Copywriting
- UI states: loading, empty, success, error, disabled, selected, expanded, collapsed
- Interaction behavior
- Assets/icons/images
- Responsive/platform notes
- Open questions

Do not invent missing states. Report them.
