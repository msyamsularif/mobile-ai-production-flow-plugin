# Jira Deep Reference Discovery

Inspect both the Jira subtask and parent story.

Scan all of these places:

- Description
- Comments
- Attachments
- Linked issues

Extract and classify all references:

- Design / Figma
- Backend TRD
- API Contract
- GraphQL schema
- OpenAPI / Swagger
- Product documentation
- Supporting documentation
- Unknown

Produce a Discovered References Report before design/backend research.
